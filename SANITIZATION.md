# Package review and publication boundary

Prepared 17 October 2026. This package is an educational extraction of a local fictional-data demonstration, not a copy of the studio website repository.

## Included

- An unbranded local HTML interface and two JavaScript modules.
- Fictional test references, sample `.test` addresses and generic demo owner values.
- Behavioral tests and a console walkthrough.
- README, tutorial, limitations and QA documentation.
- Package metadata with `private: true`, plus `.gitignore`.
- A SHA-256 manifest for the allowlisted files.
- The owner-approved MIT license.

The README names the studio as provenance. It contains no commercial CTA. The tutorial body is educational and discloses AI assistance.

## Excluded

No credentials, tokens, environment files, browser/session state, personal profile details, analytics exports, contact lists, client data, private source repositories, campaign scheduling records, videos, screenshots, Library helpers or Git metadata are included. The tests use a reserved `example.com` address only as an intentionally rejected input; it is not an actual contact.

The archive is built from an explicit file allowlist. Each member is read back from the completed ZIP, compared with the reviewed source bytes and hashed. A text scan checks common secret patterns, personal identity markers, absolute user paths, network-call APIs and unexpected files. A scan is not a guarantee that arbitrary secrets could be recognized; manual review of all included source and documentation also forms part of this check.

Runtime code contains no network calls or external dependencies. Links in the tutorial point to official technical documentation. The local browser page loads only its own modules and uses a CSP that blocks connection APIs. Python serves only this folder on loopback when started with the documented command.

## Approved public scope

The owner approved public publication of the reviewed fictional-data package under the SomethingOutThere GitHub organization with an MIT license. This publication contains the original 13 allowlisted files plus `LICENSE`; changes to existing files are limited to licensing, publication references, disclosure wording and this regenerated manifest. Runtime code and tests are unchanged.

No DEV article, Reddit comment, hosted running app, n8n showcase or new schedule is included in this publication. No personal author email is used in the initial commit: `studio@example.invalid` is an explicitly non-contact placeholder. `private: true` only blocks accidental npm publication; it does not set GitHub visibility.
